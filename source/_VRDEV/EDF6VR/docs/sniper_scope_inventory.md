## MMF01（KFF系）の追加参考例

`tools/patch_svu01_scope.py`は従来のSVU01を既定値として保ち、
`--model mmf01`で別モデルの幾何データを変更する参考プロファイルを選べます。
**MMF01の実機動作は未確認です。現在の2倍合成処理はSVU01しか判定しません。**
このプロファイルは透過の検討用で、KFF系のズーム対応を意味しません。

```powershell
python tools\patch_svu01_scope.py "<game directory>" "<scratch directory>\S_SNIPER_MMF01.RAB" --model mmf01
```

SVU01は頂点インデックスを共有する80三角形のレンズ島が2つあり、
接続した三角形を選べます。一方、MMF01の円盤状の面は同じ位置でも頂点インデックスが
分かれており、同じ島の探索では一部しか選べません。この例では、正確な元ファイルの
SHA-256を前提に、目視した形状と座標から特定した三角形番号を明示しています。
形状が似ているという理由だけで未知のモデルを自動加工する方式ではありません。

| 面 | 三角形番号（0始まり） | 数 | Z座標 | Y範囲 |
|---|---|---:|---:|---|
| 後方の円盤 | 1258–1271 | 14 | -0.009208679 | 0.151123047–0.181396484 |
| 内部の円盤 | 2216–2229 | 14 | 0.194580078 | 0.152587891–0.179687500 |
| 前方の円盤 | 2548–2559、2816–2817 | 14 | 0.414550781 | 0.143432617–0.189086914 |

この3面は、スコープの軸付近にある平面を塞ぐ三角形です。前後の2面だけを加工すると、
内部の円盤が残ります。スコープ筒の周囲の面はこの選択に含めていません。
実際に完全に透けるか、内部の他の面が邪魔しないかは、ゲーム内で確認する必要があります。

### 元データと生成結果

- 元MDB：`s_sniper_mmf01.mdb`、インデックス数8838、メッシュ数1。
- 元MDB SHA-256：`b593c2218b88b1b0bdbb1cf36cb50af02d1f2cf72fff509ccbcd0c7b6fbe44c5`
- 生成RAB SHA-256：`97b995a46d6581d69b81c436f049e4feb22d952b2dc782a12a41144583d094a3`
- 元のインデックスと生成後のインデックスを別途比較し、変更された三角形が指定した42個と一致することを確認しました。
- それ以外の三角形、インデックス領域外のMDBバイト、他のRABエントリが同一であることを確認しました。
- 加工済みMDBと、1バイト変更したMDBを入力すると、元データのハッシュ検査で拒否されることを確認しました。
- SVU01の既定プロファイルの生成結果は変更前と同じSHA-256（`a4c4fc9177de0f5bf9bd43f24bbfd0777db785cb49f07e5ce8d78c1608d5cd29`）でした。

上記の生成結果とデータ保持のチェックは、次のテストでも再実行できます。

```powershell
python tests\lens_patch_tests.py "<game directory>"
```

元の`Root.cpk`が必要です。加工済みRABは一時ディレクトリに生成して削除します。
このテストは、ゲーム内での描画結果を検証するものではありません。

生成ファイルはゲームへ導入していません。ゲームの元アーカイブは変更していません。
ゲームデータ、解析用のモデル画像、生成したRABはPRに含めていません。

## MODとして広げる際の検討事項

1. モデルごとのプロファイルに、リソース名、透過させる面、開口部の中心・軸・半径を持たせる。
2. 共有モデルを使う武器でも、姿勢、リロード、ゲーム標準ズーム、左利き、二丁持ちを確認する。
3. スコープの有無や遮蔽物を確認し、覗く位置にいないときの表示方法を決める。
4. 未知のゲームビルドやモデルはハッシュ不一致として扱い、通常表示を保つ。
5. 2倍表示の倍率、開口部の表示位置、左右の見え方、負荷を、実際のヘッドセットで確認する。

この資料は実装対象の整理と、異なる形状への加工例の提示を目的としています。
12モデルすべての透過やズームに対応済みという意味ではありません。
MDBのフィールド構造の確認には、[MDB Format documentation](https://github.com/KCreator/Earth-Defence-Force-Documentation/wiki/MDB-Format)も参照しました。
